## Hvorfor en egen fase-mappe

Fase-mappene (`011`–`014`) speiler prosjektmetodikkens fire faser. `014` ble opprettet ved prosjektoppstart for å holde strukturen konsistent. Sluttrapporten ble lagt under `005 report/` for å unngå dypt nestede stier.
